Реалізуйте модель класифікації зображень MNIST. Архітектуру класифікатора можна обрати самостійно, проте вона повинна залишатися однаковою для всіх експериментів.

Навчіть два окремі класифікатори:

Baseline: на оригінальних зображеннях MNIST.

Reconstructed: на зображеннях, реконструйованих навченою моделлю VAE.

Для другого експерименту тренувальний набір формується за формулою:

Train dataset = Decoder(Encoder(I)), де I — оригінальне зображення MNIST.

Порівняйте Accuracy обох класифікаторів на оригінальній тестовій вибірці MNIST.

Test dataset = Decoder(Encoder(I + N(0, sigma^2)))
